# Benchmark data

| File | What | Source |
| --- | --- | --- |
| `districts.csv` | 745 Indian districts with state | Derived from India Post's public all-India pincode directory |
| `place_aliases.csv` | Common city names that differ from the district name (Bangalore, Trichy) | Hand-written |
| `people.csv` | 300 full names, with Devanagari or Tamil spelling for most | Synthetic, built from common first names and surnames; not real people |
| `handwritten_variants.csv` | ~110 heard → expected pairs: STT-style misspellings, surname first, old city names, native script | Hand-written |
